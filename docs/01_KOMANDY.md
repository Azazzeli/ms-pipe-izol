# Команды

Группа: `PIPE_GROUP`. После `APPLOAD` в командной строке nanoCAD:

## PIPE_ALIGN

- Режим: **модальный**
- Действие: выбор трубы/оси → диалог выравнивания узлов
- Файлы: `AlignDlg.*`, `alignPipeCmd()` в `HelloNRX.cpp`

## PIPE_INSUL

- Режим: **прозрачная** команда (`ACRX_CMD_TRANSPARENT`) + **modeless** диалог
- Действие:
  1. `acedEntSel` — выбрать трубу / сегмент / ось
  2. Resolve оси: `CVCSUtils::getAxis` → `vCSTools::GetOIdAxisByViperEnt` → `vCSEntity::GetOIdAxis` / сам `vCSAxis`
  3. Открыть форму одной оси (вкладка «Текущая ось»)
  4. Подсветить трубы оси
- Чертёж **не блокируется** — можно зумить/панорамировать
- Повторный вызов закрывает старое окно и открывает новое

## PIPE_INSUL_ALL

- Режим: **прозрачная** + **modeless**
- Действие: сразу форма со вкладкой «Все оси / зоны»
- Список зон строится через `CollectAllAxes` + `BuildZonesForAxis`
- Клик по строке списка → подсветка труб зоны/оси
- Чекбокс «разрез по Weld» → зоны до/между/после швов с разной t

## Выгрузка

`APPUNLOAD` / выгрузка модуля → `DestroyWindow` у modeless-диалога, снятие группы команд.
