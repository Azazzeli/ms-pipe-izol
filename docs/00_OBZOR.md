# Обзор MsPipeIzol

Плагин NRX для nanoCAD + Model Studio CS: расчёт и 3D-назначение теплоизоляции.

## Команды

| Команда | Назначение |
|---------|------------|
| `PIPE_INSUL` | Одна ось (выбор трубы/оси) |
| `PIPE_INSUL_ALL` | Все оси / зоны |

Диалог **модальный** (до закрытия блокирует CAD) — безопасно при `APPUNLOAD`.

## Норма

- **НР 34-70-118-87**, расположение: **помещение**
- `K=1`, `tвозд=25 °C` (регион в UI не используется)
- На осевую параметры **не пишутся**
