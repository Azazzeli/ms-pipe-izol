# Теплоизоляция — логика и нормы

## Источники норм

1. **НР 34-70-059-84 / таблицы для помещений (котлы / теплосети)** — плотность теплового потока `q` по DN и t теплоносителя.
2. **СП 61.13330** — таблицы 4/5 (от ожога / безопасность поверхности), коэффициент запаса **K**:
   - DN ≤ 100 → K = 1.2
   - DN > 100 → K = 1.15
3. λ(tm) минеральной ваты / типичный утеплитель — из расчётного модуля `InsulCalc`.

Итоговая толщина: **max(δ по q, δ от ожога)**, округление вверх до ряда толщин.

Справка по методике (внешний обзор): edu.truboprovod.ru → раздел «Изоляция».

## Входные данные UI

- Регион РФ (коэффициент / расчётная t наружного воздуха для наружной прокладки — в коде заложены регионы)
- Среда: вода (котловая/теплосеть) / пар
- Температура среды t, °C
- Наружный диаметр / DN с оси (`Diameter`, `PART_PIPE_DIAMETER`, `DN`, `PART_PIPE_DN`)

## Назначение в модель

На подсегменты / трубы:

- `PART_INSULATION_THICKNESS` (и связанные PART_*)
- Толщина через API изоляции Model Studio (`SetInsulationThickness` на оси при одном зоне)

На ось дополнительно пишутся:

- температура среды
- регион
- имя среды  
(через `SetParameter` / параметры оси)

## Зоны (PIPE_INSUL_ALL)

- Ось → сегменты (`GetSegCount` / `GetSeg`) → подсегменты (`SSeg_GetArr` / Sorted)
- Сварные швы: `Weld_GetArr` + `Weld_Dist` на `vCSSegment2`
- Без разреза: одна зона «вся ось»
- С разрезом: N швов → N+1 зон (до / между / после), у каждой свои t/среда/δ
